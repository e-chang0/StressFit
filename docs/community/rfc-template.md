# RFC-0000: 제안 제목

- 상태: 의견 수렴 / 채택 / 수정 후 채택 / 보류
- 작성일: YYYY-MM-DD
- 의견 수렴 기한: YYYY-MM-DD(한국 시간)
- 관련 이슈 또는 ADR: 링크

## 배경

지금 무엇이 불편하거나 결정되지 않았는가?

## 제안

무엇을 바꾸려는가? 필요하면 간단한 입력·출력 예시를 적는다.

## 다른 방법

비교할 방법과 각각의 장단점을 적는다.

## 단점과 부담

추가 작업이나 놓칠 수 있는 경우를 적는다.

## 의견을 받고 싶은 점

답하기 쉬운 질문 2~3개를 적는다.

## 결정 기록

처음에는 '의견 수렴 중'으로 둔다. 이후 실제 의견, 바뀐 점, 최종 이유와 후속 이슈를 기록한다.
