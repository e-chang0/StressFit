# 13주차 Lean Startup 실험

## 진행 상황

10개 가상 페르소나에 대해 현재 추천 함수를 직접 실행하고 결과를 저장했다. 각 피드백은 이 대화의 LLM이 시나리오와 코드 결과를 바탕으로 작성한 가상 평가다. 실제 사람이 서비스를 사용하거나 응답한 기록은 아니다. [시나리오와 평가](personas.json) · [함수 실행 결과](persona-results.json)

실제 방문자 모집이 어려워 요청에 따라 LLM 페르소나를 이용한 시뮬레이션을 진행한다. 결과는 실제 사용자 조사나 실제 서비스 이용 지표가 아니다.

[14일 가상 계산과 잠정 결정](forecast.md)은 14일 운영 결과를 미리 예측한 계산이며, 실제 2주 운영 기록이 아니다. 같은 판단을 반복해 새 데이터를 얻지 못하는 문제를 확인하여 실험 방식의 Pivot을 잠정 제안했다.

추가로 [대화에서 진행한 압축 모의 실험](chat-report.md)에 10개 페르소나의 가상 1·2주차 반응 20개와 A/B 집계를 정리했다. 한 LLM이 한 번에 작성한 응답이며, 20회의 독립 호출이나 실제 2주 운영 기록은 아니다.

## 실험 계획

- 질문: 추천 버튼의 문구를 바꾸면 추천 요청 비율이 높아질까?
- 가설: B 문구가 A보다 추천 버튼 클릭률을 5%p 이상 높일 것이다. 이 수치는 사전에 정한 탐색 기준이며 통계적 유의성을 뜻하지 않는다.
- A: `내 루틴 확인하기 →`, B: `나에게 맞는 루틴 찾기 →`. `recommendation-cta-v1` 플래그가 켜져 있으면 브라우저 ID에 따라 A/B를 배정한다. 기존 실험이므로 이전 실험 로그는 이번 결과에 섞지 않는다.
- 핵심 지표: 노출된 서로 다른 브라우저 ID 중 노출 이후 추천 버튼을 한 번 이상 누른 ID의 비율. 추천 성공 및 오류 건수는 원본 이벤트에서 별도로 확인한다.
- 기간: 2026년 11월 28일 15:56:31부터 12월 12일 15:56:31까지, 한국 시간 기준 14일. 시작은 첫 시뮬레이션 기록 시각에 가깝게 정했다.
- 자료: 가상 인물 10명에 대해 LLM이 한 번 작성한 클릭 판단을 자동화 코드가 하루에 한 번 반복한다. 각 기록의 ID는 실제 플래그 코드로 A/B에 배정하며, 공통 추적 코드로 노출과 클릭 이벤트를 만든다. 각 날짜 기록은 [simulation](simulation)에 저장한다.
- 실험 상태: 진행 중. 실행 누락은 나중에 가짜 날짜로 채우지 않는다.

## 가상 평가 방법

LLM에 서로 다른 상황, 입력값, 기대와 불편을 가진 인물 10명을 작성하도록 요청했다. 실제 `recommendRoutine` 함수에 각 입력을 넣어 나온 반환값을 기록하고, 그 결과에 맞춰 각 인물 관점의 짧은 피드백을 작성했다. 웹 화면을 실제로 조작한 사용성 시험은 아니다. 동일한 LLM이 인물과 평가를 작성했으므로 다양한 의견을 보장하지 않는다.

반복된 의견은 운동 동작 설명 부족, 강도 판단의 어려움, 추천 시간이 입력보다 짧은 이유 안내다. 통증이 있는 경우 휴식과 전문가 상담 안내가 나오는 것도 확인했다. 개선 후보와 우선순위는 [백로그](backlog.md)에 적었다.

재실행: `node scripts/week13-personas.js`. 이 명령은 현재 코드로 결과를 다시 만들므로 코드가 달라지면 기존 결과도 바뀐다.

## 집계와 주간 보고

`Week 13 persona simulation` Actions가 6시간마다 실행되어 해당 24시간 구간에 기록이 없다면 한 번 기록한다. 1~7일차와 8~14일차의 집계는 [가상 실험 보고서](simulation-report.md)에 저장한다. 스케줄 지연, 저장 실패로 빠진 날짜는 보고서에 표시한다. 같은 인물의 같은 판단이 반복되므로 노출 횟수는 독립적인 사용자 수가 아니다. 매일 LLM을 다시 호출하지 않으며, 결과로 실제 사용자 선호를 추론할 수 없다.

별도의 `Week 13 experiment report` Actions는 브라우저에서 직접 내보낸 자료를 집계하는 용도다. 가상 실험 결과와 섞지 않는다. 두 워크플로 모두 기본 브랜치에 반영되어야 정기 실행된다.
