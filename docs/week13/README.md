# 13주차 Lean Startup 실험

## 진행 상황

10개 가상 페르소나에 대해 현재 추천 함수를 직접 실행하고 결과를 저장했다. 각 피드백은 이 대화의 LLM이 시나리오와 코드 결과를 바탕으로 작성한 가상 평가다. 실제 사람이 서비스를 사용하거나 응답한 기록은 아니다. [시나리오와 평가](personas.json) · [함수 실행 결과](persona-results.json)

실제 방문자 모집은 어렵다는 조건이다. 과제 문구만으로는 2주 A/B 지표도 가상 사용자로 대신할 수 있는지 확인되지 않았다. 교수자에게 확인하기 전에는 가상 수치를 실제 운영 결과로 제출하지 않는다.

## 실험 계획

- 질문: 추천 버튼의 문구를 바꾸면 추천 요청 비율이 높아질까?
- 가설: B 문구가 A보다 추천 버튼 클릭률을 5%p 이상 높일 것이다. 이 수치는 사전에 정한 탐색 기준이며 통계적 유의성을 뜻하지 않는다.
- A: `내 루틴 확인하기 →`, B: `나에게 맞는 루틴 찾기 →`. `recommendation-cta-v1` 플래그가 켜져 있으면 브라우저 ID에 따라 A/B를 배정한다. 기존 실험이므로 이전 실험 로그는 이번 결과에 섞지 않는다.
- 핵심 지표: 노출된 서로 다른 브라우저 ID 중 노출 이후 추천 버튼을 한 번 이상 누른 ID의 비율. 추천 성공 및 오류 건수는 원본 이벤트에서 별도로 확인한다.
- 기간: 배포 및 수집 방식이 확인된 시점부터 연속 14일. 시작과 종료 시각을 아래 기록에 실제 시각으로 적는다. 마감 12월 13일 23:59에 맞추려면 늦어도 11월 29일 23:59에 시작해야 한다.
- 자료: 각 브라우저의 실습실에서 JSON을 내려받아 `events/`에 모은다. 서버에 자동 전송되지는 않는다. 브라우저별 ID이므로 같은 사람이 여러 기기를 쓰면 별도 ID로 잡힌다.
- 실험 상태: 준비 중. 시작·종료 시각과 결과는 아직 없다. 데이터 수집 출처와 기간을 정한 후 시작한다.

## 가상 평가 방법

LLM에 서로 다른 상황, 입력값, 기대와 불편을 가진 인물 10명을 작성하도록 요청했다. 실제 `recommendRoutine` 함수에 각 입력을 넣어 나온 반환값을 기록하고, 그 결과에 맞춰 각 인물 관점의 짧은 피드백을 작성했다. 웹 화면을 실제로 조작한 사용성 시험은 아니다. 동일한 LLM이 인물과 평가를 작성했으므로 다양한 의견을 보장하지 않는다.

반복된 의견은 운동 동작 설명 부족, 강도 판단의 어려움, 추천 시간이 입력보다 짧은 이유 안내다. 통증이 있는 경우 휴식과 전문가 상담 안내가 나오는 것도 확인했다. 개선 후보와 우선순위는 [백로그](backlog.md)에 적었다.

재실행: `node scripts/week13-personas.js`. 이 명령은 현재 코드로 결과를 다시 만들므로 코드가 달라지면 기존 결과도 바뀐다.

## 집계와 주간 보고

실습실에서 내려받은 파일을 `events/`에 넣은 뒤 `node scripts/week13-report.js`를 실행한다. 중복 이벤트 ID를 제거하고 실험 ID별 노출 이후 클릭을 브라우저 ID로 집계한다. 다른 출처나 기간의 자료는 별도로 관리해야 한다. [현재 집계](latest-report.md)는 아직 자료가 없는 상태다.

`Week 13 experiment report` Actions는 기본 브랜치에 올라간 뒤 매주 월요일 한국 시간 오전 9시와 수동 실행 시 집계 결과를 실행 요약과 artifact에 남긴다. GitHub에 올린 파일만 집계하며, 브라우저에서 파일을 자동으로 가져오지는 않는다. 주간 집계 시점과 운영 시작·종료 시점이 다를 수 있으므로 최종 보고 때 별도 확인이 필요하다.

## 기록 및 결정

| 항목 | 현재 상태 |
|---|---|
| 시작 / 종료 | 미시작 / 미종료 |
| 1주차 / 2주차 결과 | 자료 없음 / 자료 없음 |
| Pivot 또는 Persevere | 보류: 비교할 결과가 없음 |

자료가 충분하면 B와 A의 클릭률 차이, 표본 수, 오류 및 피드백을 함께 검토한다. 목표에 못 미치거나 자료가 부족하면 이유를 적고 변경 또는 추가 실험을 결정한다. 작은 표본에서는 차이가 우연일 수 있다.
