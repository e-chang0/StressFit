# StressFit Wiki

StressFit은 오늘의 상태와 운동할 수 있는 시간, 장소를 입력하면 운동 루틴을 추천하는 학기 프로젝트다. 현재는 HTML/CSS/JavaScript로 만든 학습용 추천 데모가 있다. React·FastAPI·데이터베이스를 사용하는 전체 서비스는 앞으로 구현할 계획이다.

처음 들어왔다면 아래 순서로 읽으면 된다.

1. [Getting Started](https://github.com/e-chang0/StressFit/wiki/Getting-Started): 프로젝트 소개와 저장소 내려받기
2. [Development Guide](https://github.com/e-chang0/StressFit/wiki/Development-Guide): 작업 순서와 문서 수정 방법
3. [Troubleshooting](https://github.com/e-chang0/StressFit/wiki/Troubleshooting): Git, 문서 링크, 자동화에서 막혔을 때 확인할 내용

구현할 기능과 일정은 [README](https://github.com/e-chang0/StressFit/blob/main/README.md), 진행할 작업은 [프로젝트 보드](https://github.com/users/e-chang0/projects/4)에서 확인할 수 있다.

질문과 설계 의견은 [Discussions](https://github.com/e-chang0/StressFit/discussions)에, 수정할 오류와 구체적인 작업은 [Issues](https://github.com/e-chang0/StressFit/issues)에 남긴다. 기술을 선택한 이유는 [ADR](https://github.com/e-chang0/StressFit/tree/main/docs/adr)에 기록한다.
